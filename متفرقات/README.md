# متفرقات (تصاميم مؤقتة)

هذا المجلد للتصاميم المؤقتة والتجارب: مسودات، نسخ تجريبية، أفكار سريعة، ملفات لعميل واحد.

- اللي يتم اعتماده ونشره ينتقل إلى مجلد `جاهز/`.
- اللي ما نحتاجه بعد انتهاء الشغل يُحذف من هنا.
- التسمية: `الموضوع - كامي vN` مثل باقي الملفات (مثال: `بوستر عرض الشتاء - كامي v1.png`).
