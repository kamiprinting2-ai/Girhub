# Kami Printing - Instagram templates

Brand: Kami Printing · @kami.printing · 66606959 · Isa Town (Bahrain)
Colors: cream #F4F0E4 · dark green #2E3B2A · sage #9AA88A / #CDD6BF · blush #ECD3CE · rose #D3959B
Fonts: Alexandria (Arabic), Fraunces (Kami wordmark)

- `kami-posts.html` all 7 templates (1080x1350, 4:5 Instagram)
- `render.js` renders them to `out/*.png`: `node templates/render.js`
- photos: put files in `templates/photos/` and run `node templates/render.js "p07=photos/work-1.jpg&p01=photos/x.jpg"`
- real logo: save it as `brand/logo.png` (transparent PNG) and it replaces the rebuilt wordmark automatically

| id | use |
|---|---|
| p01-hook | question hook (معاملة؟ ولا كأنها كانت!) |
| p02-service | one service + price sticker |
| p03-cta | brand / call to action |
| p04-number | big number post |
| p05-prices | price list card |
| p06-occasion | occasions (dark green, line art) |
| p07-work | من أعمالنا, work photo |
