## ثابت لأي شخصية
- ألوان ملابسها من ثيم كامي: كريمي، أخضر سيج، وردي فاتح.
- الخلفيات: محل كامي أو بيت بإضاءة النهار.
- بدون كتابة أو شعارات داخل الصورة المولّدة (الشعار نحطه فوق).
- نذكر في الكابشن أو الحقوق إن الشخصية مولّدة بالذكاء الاصطناعي إذا طلبت المنصة.
